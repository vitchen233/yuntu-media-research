# Security

Do not commit or share API keys, tokens, cookies, browser sessions, customer data, private messages or unredacted personal data.

The Skill must not bypass authentication, CAPTCHAs, paywalls or platform access controls. RedFox and browser access remain subject to the user's authorization and the relevant service terms.

Report vulnerabilities through a GitHub issue without sensitive reproduction data. Contact details will be added after the public remote is created.
